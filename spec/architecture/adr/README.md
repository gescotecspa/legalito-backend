# ADR

En esta carpeta se registran decisiones tecnicas transversales del backend.

## Cuando crear un ADR

- cambia la estrategia de autenticacion
- cambia la politica de persistencia
- se incorpora una nueva integracion base
- se modifica una regla comun de seguridad, logging o arquitectura

## Formato sugerido

Usar la plantilla `spec/templates/adr.template.md`.
