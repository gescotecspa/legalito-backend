# Glosario

- `usuario`: persona autenticable dentro de la plataforma.
- `plataforma Legalito`: producto pensado como CRM legal con experiencias movil y web para centralizar gestion juridica.
- `CRM legal`: sistema para organizar clientes, causas, agenda, comunicaciones, documentos y seguimiento operativo de un estudio o profesional legal.
- `assistant`: entidad asociada a apoyo operativo o administrativo dentro del sistema.
- `case`: causa o caso juridico gestionado por la plataforma.
- `colaborador IA`: capacidad futura de apoyo al abogado para jurisprudencia, analisis de casos, revision de antecedentes o borradores, sin sustituir juicio profesional humano.
- `folio`: identificador o registro asociado a seguimiento documental o judicial.
- `notification`: aviso generado por la plataforma para un usuario.
- `email account`: cuenta de correo externa asociada a un usuario para lectura de mensajes.
- `mail reader`: proceso que consulta correos no leidos desde una cuenta IMAP.
- `event`: evento generado desde el backend, con opcion de enviar invitacion `.ics`.
- `reset code`: codigo temporal de recuperacion de contraseña.
- `status`: estado funcional de una entidad, usado por ejemplo para usuarios.
- `terms and conditions`: version aceptada de terminos y condiciones asociada al usuario.
