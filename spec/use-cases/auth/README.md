# Use Cases Auth

Casos de uso de autenticacion, registro y recuperacion de contraseña.

## Casos documentados

- `UC-001-autenticacion-de-usuario.md`: autenticacion de usuario activo mediante email y contraseña.
- `UC-002-registro-de-usuario.md`: registro de usuario nuevo con asignacion de estado activo y terminos vigentes.
- `UC-003-solicitud-de-recuperacion-de-contrasena.md`: solicitud de codigo temporal de recuperacion.
- `UC-004-restablecimiento-de-contrasena-con-codigo.md`: cambio de contraseña usando codigo temporal.
