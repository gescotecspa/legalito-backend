# Use Cases

Esta carpeta documenta comportamiento de negocio.

## Organizacion

Los casos de uso deben agruparse por dominio funcional. Ejemplos:

- `auth/`
- `users/`
- `notifications/`
- `events/`

## Cuando agregar un use case

- aparece un flujo nuevo para usuario o sistema
- cambia una validacion funcional
- cambia el resultado esperado de un proceso

## Nombres sugeridos

- `auth/UC-001-registro-de-usuario.md`
- `auth/UC-002-recuperacion-de-contrasena.md`

## Tareas asociadas

Si hace falta seguimiento operativo, crear un archivo hermano con sufijo `.tasks.md`.
